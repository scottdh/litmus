# Design skills

The design process relies on these skills. They're installed in `~/.claude/skills` on Scott's machine and aren't committed, because they carry no licence file. Until that changes, the design passes only run where they're installed. If they're missing, say so on the issue rather than skipping the pass.

| When                                         | Skill                                  |
| -------------------------------------------- | -------------------------------------- |
| Before any UI PR lands (required)            | `emil-ui-review`, `emil-unslop-design` |
| Picking colours, tokens, dark mode, contrast | `emil-color`                           |
| Type, scales, wrapping                       | `emil-typography`                      |
| Hierarchy, spacing, layout, copy             | `emil-design-foundations`              |
| Cards, borders, shadows, elevation           | `emil-surfaces`                        |
| Any motion                                   | `emil-animations`                      |
| Component APIs                               | `emil-component-design`                |
| Forms and buttons                            | `emil-forms-and-inputs`                |
| Keyboard, screen readers, touch              | `emil-touch-and-accessibility`         |
| Comparing directions                         | `emil-prototype`                       |
| Final details                                | `emil-ui-polish`                       |
| Long lists, jank                             | `emil-performance`                     |
| Updating `DESIGN.md`                         | `emil-design-system-docs`              |
| Cleaning up agent-written code               | `emil-unslop-code`                     |
| Before a launch or demo                      | `emil-prep-for-prod`                   |
